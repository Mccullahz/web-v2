# the charge

One continuous scroll-driven flight down a roastery hall — one station per
project, the roast drum swallows the camera mid-flight, and the ride lands on
the mug lineup. Lives at `/gui` behind the top-left scene switcher.

## Files

| file | owns |
| --- | --- |
| `projects.ts` | flight order + per-project copy/shot — the single source of truth |
| `layout.ts` | the approved camera path (sway, drum dip, roll) and scroll↔distance math |
| `theme.ts` | dark/light palettes + the mobile/desktop quality tier |
| `ChargeScene.tsx` | Canvas, ScrollControls rig, and the whole DOM layer (card, rail, skip) |
| `ChargeSet.tsx` | everything read out of the GLB: tinting, anchors, drum spin, panels, embers |
| `FinaleMugs.tsx` | the experimental mug lineup at the end |

## The Blender loop

The set is `public/models/charge-set.glb`, generated by
`npm run charge:set` (`scripts/export-charge-set.mjs`). It is the layout
source of truth — the scene reads node positions out of it at runtime, so you
can iterate entirely in Blender:

1. Blender → File → Import → glTF 2.0 → `charge-set.glb`
2. Move/reshape whatever you like. **Keep the node and material names** —
   `Station_XX`, `Drum_XX`, `DrumSpinner`, `Panel_XX`, `LampGlow_XX`,
   `MugSpot_XX`, `Finale`, and the `M_*` materials are the contract with the
   code.
3. Export → glTF Binary (+Y up, the default) back over `charge-set.glb`.

Moving a `Station_XX` along Z moves that beat of the flight (card timing,
rail target, everything). Moving the `Drum_XX` moves the camera's dip with it.
Material colours in the file don't matter — the scene re-tints `M_*` materials
per theme at runtime; put real texture work in new materials if needed.

## Adding a project

1. Add an entry to `projects.ts` in flight order (exactly one `kind: "drum"`).
2. Bump `STATIONS` (and `DRUM_INDEX` if it moved) in
   `scripts/export-charge-set.mjs`, then `npm run charge:set`.
3. Drop a shot in `public/images/` and point `shot` at it.

Scroll length, rail ticks, mug count and the flight plan all follow from that.
